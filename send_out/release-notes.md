# Vocabulary Trainer — v2.1.0

Installing this over your current copy **keeps your saved words and collections**.
Nothing in the install process touches them.

## What's new since your current version

- **Resize the floating character.** Settings → Widget now has a size slider
  (50%–300%), so you can make it bigger or smaller to taste.
- **Cleaner word-type labels** in the Collect card — the noun/verb/adjective/
  adverb/phrase labels used to get visually cut off; they're readable now.
- **Smarter practice scoring.** Getting a word wrong now means you need to get it
  right *more* times before it's considered learned — not just a lower score.
  For example: normally you need 3 correct answers to master a word. Miss it once,
  and it now takes 4 correct answers instead of 3.

## Also included

- The installer is now a proper `.exe` (was a `.cmd` script before). Nothing to do
  differently — just run it the same way.
