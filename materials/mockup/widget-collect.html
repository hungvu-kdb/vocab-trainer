Switching to "Type it myself" cancels any in-flight lookup and replaces the read-only result panel with editable Meaning and Example fields. Both are optional — leaving Meaning blank saves the word with Type only, same as an unresolved Auto-lookup. Save never waits on a dictionary in this mode, and a lookup response can never overwrite what the user typed.
